# Audi A6 C4 Avant – City Drive 2.0

Ein kleines, direkt im Browser spielbares 3D-Fahrspiel mit einem schwarzen Audi A6 C4 Avant und einer simulierten Stadt.

## Spielen

Öffne die veröffentlichte GitHub-Pages-Adresse auf deinem Smartphone oder PC.

Auf dem Smartphone die eingeblendeten Bildschirmtasten nutzen; am PC **WASD** oder die **Pfeiltasten**. Weitere Tasten: **Leertaste** Handbremse, **V** Kamera, **R** Neustart, **P** Pause.

## Technik

- Reines HTML, CSS und JavaScript (WebGL), ohne Build-Schritt oder externe Bibliotheken.
- GitHub Pages kann die Datei `index.html` direkt ausliefern.
- Optimiert für Touch-Bedienung und Desktop-Browser mit WebGL-Unterstützung.

## Entwicklungsziele

Verbesserungen an Grafik, Fahrphysik, Fahrzeugmodell, Stadtgestaltung, Verkehr, Performance und Spielmechaniken.

> Prototyp, keine Verbindung oder offizielle Zusammenarbeit mit Audi AG oder Rockstar Games.
